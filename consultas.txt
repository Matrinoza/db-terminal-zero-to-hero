[EN] ENGLISH VERSION
----------------------------------------------------------------------
Task: Safely modify and delete records using standard SQL clauses.
Engine: SQLite 3

1. Data Mutation (UPDATE)
Correct syntax discovered through iterative debugging:
sqlite> UPDATE students SET name = 'Lautaro', age = 21 WHERE id = 4;

2. Data Deletion (DELETE)
sqlite> DELETE FROM students WHERE id = 3;

3. Concept Learned: One-Liner Execution
Databases can be queried directly from the OS shell (Bash) without entering the interactive prompt:
$ sqlite3 -column -header escuela.db "SELECT * FROM students;"
