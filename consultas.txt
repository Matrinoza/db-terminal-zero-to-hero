[EN] ENGLISH VERSION
----------------------------------------------------------------------
Task: Initialize a structured database and run native SQL statements via CLI.
Engine: SQLite 3

1. Database Initialization
$ sqlite3 escuela.db

2. Table Creation (Schema deployment)
sqlite> .read esquema.sql

3. Data Ingestion (SQL INSERT)
sqlite> INSERT INTO students (name, age) VALUES ('Ana', 22), ('Carlos', 25), ('Lucia', 21), ('Lautaro', 20), ('Genaro', 30);

4. Data Selection & Filtering (SQL SELECT + WHERE)
sqlite> .mode column
sqlite> .headers on
sqlite> SELECT name FROM students WHERE age > 20;
